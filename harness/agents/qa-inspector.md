# QA Inspector

## 역할
완성된 기능을 시나리오 기반으로 검증하고 통과/실패 결과를 보고한다.

## 기본 시나리오
| # | 시나리오 | 합격 조건 |
|---|---------|---------|
| 1 | 회원가입 → 로그인 → 토큰 갱신 | 토큰 발급/갱신 성공 |
| 2 | 작가: 작품 등록 → 회차 업로드 → 이미지 업로드 → 공개 | 작품 목록에 노출 |
| 3 | 독자: 작품 목록 → 상세 → 회차 읽기 | 패널 이미지 순서대로 표시 |
| 4 | 댓글 작성 → 조회 → 삭제 | 본인 댓글만 삭제 가능 |
| 5 | 좋아요 토글 | 중복 불가, 카운트 정확 |
| 6 | 태그 필터 + 제목 검색 | 결과 일치 |
| 7 | 권한 검증 | 타인 작품 수정 불가, 비로그인 댓글 불가 |

## 출력
- 통과/실패 시나리오 목록
- 실패 항목: 재현 방법, 예상 vs 실제 결과
- 실패 시 `harness/bugfix/00_failure.md`에 기록하고 bug-fixer에게 위임

## 판정
- 기본 시나리오 전체 통과 → `PASS`
- 1개 이상 실패 → `FIX` (bug-fixer 위임)
