## 특이 사항 메모

1. **로드릭 머리색 리스크**: 2화 전 컷에서 ash-grey 유지 확인. platinum-blonde로 새지 않음. 특히 밝은 조명 컷(컷2, 21, 44)에서도 grey 톤 유지됨. 리스크 통과.

2. **붉은 점 연속성 (물증 비트)**:
   - 컷29(세라 귀 뒤 최초 노출): 점 식별 불가 → FIX
   - 컷34(초상화 귀 뒤): 점 확인됨 → PASS
   - 컷35(세라 귀 뒤 교차 클로즈업): 점 확인됨, 동일 위치 → PASS
   - 컷37(세라 손이 점에 닿음): 점 위치 확인 → PASS
   - **컷29 FIX가 선행되어야 서사 흐름이 완성됨.**

3. **초상화 드레스 색**: 컷6에서 드레스가 다소 어둡게 보이나 크림/아이보리 계열 범주 내로 판단. 컷7, 8, 33, 40, 46에서 크림 비단으로 확인됨.

4. **카밀라 입가 흉터**: 조명이 어두운 컷(30, 31, 45)에서 불선명하나 구조적 이유로 허용. 밝은 컷 생성 시 흉터 필수 표시 권고.

5. **컷20 말풍선 텍스트 누락**: 말풍선은 있으나 내용이 비어 있음. 아트 결함/텍스트 이슈(아트 결함 검수관 담당).
