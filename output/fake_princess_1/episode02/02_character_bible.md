## 캐릭터별 2화 핵심 (보이스·표정·일관성)

### 세라피나 (`sera`)
- **보이스**: 표면은 또박또박 자제, 위기·본색에선 직설("사람 잘못 봤어요", "나만 입 다물면 되잖아요"). 내레이션은 냉정한 생존 계산. 수락(컷41)·협상(컷42~43)에서 **떨림을 죽인 목소리**(1화 빚쟁이 앞 톤 동일).
- **2화 아크**: 거절(자기 없음 항변) → 우회 시도(틈 잼) → 물증 앞 무너짐 → 저울질 → 수락 + 역협상(주도권 일부 회수). '읽어서 사는' 무기가 제 얼굴 앞에서 처음 작동 안 함(끝 훅).
- **외형 고정(1화 동일)**: amber iris / light-chestnut long wavy hair(묶지 않음) / upturned almond eyes. 평민 의상(회갈 원피스·해진 숄). **오른쪽 귀 뒤 붉은 점**(평소 머리카락에 가림 → 컷29 노출 → 컷46 다시 덮음).

### 로드릭 (`roderick`)
- **보이스**: 간결·차가운 거래. 감정 호소 없이 손익으로 가둔다("간단한 거래지", "그 조건, 내가 보증하지"). 세라의 영리함에 화내지 않고 음미·인정("영리하군").
- **2화 처리**: 컷2에서 **빛 속으로 걸어 들어오며 얼굴 첫 정면 노출** — 1화에서 장갑·장부·문장반지 소품으로만 비춘 의도를 받아 '재상 본인'의 무게를 세운다. 거의 움직이지 않고 '말'로 압박(정적 연출).
- **외형 고정(1화 동일)**: slate blue-grey narrow eyes / ash-grey 뒤로 넘긴 머리 / clean-shaven 마른 얼굴(수염 텍스처 금지) / 남색 재상복 · 장부책 · 문장반지.

### 카밀라 (`camilla`)
- **보이스**: 2화 대사 단 1줄("…재상님", 컷31) — 평소 무뚝뚝함이 붉은 점 목격 순간 **흔들린다**. 과묵하나 한 점도 안 놓치는 칼잡이.
- **2화 처리**: 1화에선 칼자루 손/전신 위주 → 2화에서 **얼굴 정점**(컷30 목격의 억제된 충격, 컷45 도구→사람 떡밥 시선). 칼자루 손은 컷22에서 위협 인서트로 한 번 더(거둘 필요도 없다는 듯 천천히 떨어짐).
- **외형 고정(1화 동일)**: grey-green eyes / dark-umber tight low knot / 입가 흉터 / 허리 세장검.

### 초상화 아리아드네 (`SERA_REF` 변형)
- **핵심 = 1화 컷41~46과 동일 그림이어야 함**(같은 방·같은 위치·같은 금관·크림 비단). 세라 얼굴 정체성 그대로 + 가느다란 금관 + 크림 비단 왕녀 드레스. prompt에 "same portrait as Ep01 cut43; same face identity as SERA_REF wearing a slender gold crown and cream silk royal gown; this is the dead princess portrait, deliberately identical to Sera's face" 명시.
- **귀 뒤 붉은 점 = 물증의 핵.** 컷34(초상화 점)는 **1화 컷43의 점 위치를 SSOT로 고정**해 동일 위치(오른쪽 귀 뒤)로 그린다. 컷35(세라 점)와 같은 구도로 교차 → '같은 자리·같은 점' 가독.

## 컷 프롬프트 연결 규칙 (재진술)
- 각 컷 prompt에 등장 인물의 ref token + sheet 경로 + 시그니처 피처 문장(정의서와 동일 표현) + 금지 변형을 반복.
- 정체성 문자열엔 표정 상태 금지(구조·색만). 표정은 `expression` 블록으로 분리, 정점 컷은 근육 단위 묘사.
- **연속성 고정값**: 초상화·붉은 점 위치는 1화 컷43을 단일 소스로 참조(2화에서 새로 위치 정의 금지). 로드릭/카밀라/세라 외형은 1화 definition.md = 정답.
