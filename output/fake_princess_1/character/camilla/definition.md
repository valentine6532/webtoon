# 카밀라 — 인물 정의서

- **이름:** 카밀라 / 표시 이름 "카밀라"
- **역할:** 세라의 호위 겸 조련자. 진짜 왕녀 아리아드네를 모셨던 호위무관. 시리즈 주요 조력자. (1화에선 '칼 찬 여자'로 등장.)
- **한 줄:** 한 번 지키지 못한 얼굴을 두 번은 잃지 않겠다는 죄책감의 검.
- **성별/나이/종족:** 여 / 30대 / 인간
- **성격:** 무뚝뚝·과묵·실전형. 처음엔 세라를 도구로 대하나 점점 '세라'로 아낀다.
- **말투:** 짧고 건조한 명령조. 정(情)은 거칠게 드러난다.
- **목표/약점:** 세라를 살려 왕녀로 세우는 것 / 진짜 왕녀를 못 지킨 죄책감.

## 고정 외형 (정체성 = 구조·색만)
- 얼굴형: 각진 윤곽, 날카로운 눈매, 입가에 옅은 흉터 한 줄(왼쪽 입꼬리 위).
- 머리: **짙은 흑갈색, 뒤로 단단히 묶은 낮은 번/포니**(잔머리 정리).
- 눈: **회녹색(grey-green)**.
- 체형: 큰 키, 다부진 무관 체격.

## 의상/소품
- 어두운 가죽·금속 혼합 호위 무관복(소매 좁음, 활동성). 허리에 **세장검(가는 장검) 한 자루**(항상 휴대 — 식별 소품). 가죽 장갑.
