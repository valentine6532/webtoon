# 세라피나 "세라" — 인물 정의서

- **이름:** 세라피나(세라) / 표시 이름 "세라피나"
- **역할:** 주인공(여주). 빈민가 평민 → 죽은 왕녀 아리아드네의 대역.
- **한 줄:** 굶주림 속에서 사람을 '읽어' 살아남은 생활형 생존자. 무기는 혈통이 아니라 관찰과 거짓말.
- **성별/나이/종족:** 여 / 19 / 인간
- **성격:** 영민·침착·계산적. 표면은 또박또박, 위기엔 직설 본색. 동생들 앞에선 다정한 가장(연기).
- **말투:** 평소 정제된 말씨, 위기엔 평민 직설. 내면 독백은 냉정한 생존 계산.
- **목표/약점:** 동생들을 살리는 것 / 죄책감, 동생이 인질이라 도망칠 수 없음.

## 고정 외형 (정체성 = 구조·색만)
- 얼굴형: 갸름한 계란형, 살짝 치켜올라간 눈꼬리, 또렷한 눈매.
- 머리: **연갈색(웨이브 도는 긴 생머리)**, 평민 시절엔 질끈 묶거나 풀어 헝클어짐.
- 눈: **호박색(앰버)**.
- 체형: 마른 편이나 노동으로 다져진 단단함. 19세.
- 식별 표식: **오른쪽 귀 뒤, 머리카락에 가려진 작고 붉은 점**(초상화의 왕녀와 동일 — 떡밥. 웹툰 1화에선 머리에 가려 노출 안 함, 2화 리빌).

## 의상/소품
- **평민 세라(1화):** 낡은 회갈색 원피스 + 해진 숄, 거친 앞치마. 장신구 없음. 손끝이 거칠다.
- **(참고) 왕녀 아리아드네 초상화:** 같은 얼굴 + 가느다란 금관 + 호박색/크림 비단 드레스. → 초상화 컷은 세라 face 시트 + 왕관/드레스로 생성.
